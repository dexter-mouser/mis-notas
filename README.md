# Mis notas

Notas y resúmenes propios de libros de programación.

## Contenido

| Nota | Qué es |
| --- | --- |
| [Clean Code por capítulos](https://dexter-mouser.github.io/mis-notas/clean-code-resumen.html) | Resumen por capítulos de *Clean Code* (Robert C. Martin), con ejemplos de código antes y después, y una lista de chequeo. |

## Cómo verlo

- **En línea:** las notas se publican con GitHub Pages desde la rama `main`, en `https://dexter-mouser.github.io/mis-notas/`.
- **En local:** no necesita instalación. Abre el archivo `.html` en cualquier navegador.

## Cómo funciona

- Cada nota es una sola página HTML, con el CSS y el JavaScript dentro del mismo archivo.
- Solo carga desde internet las fuentes de Google Fonts. Sin conexión, usa las fuentes del sistema.
- Se adapta al tema claro u oscuro del sistema y al ancho del móvil.
- Las marcas de la lista de chequeo se guardan en el `localStorage` del navegador. No salen de ese navegador.

## Aviso

Los resúmenes y ejemplos están escritos con palabras propias y no reproducen el texto de los libros. Para el contenido completo, consulta las obras originales.
